# אלבום המטבעות שלי

אפליקציית אלבום (PWA) לאספני מטבעות: מסמנים מה יש ומה חסר, מצלמים כל מטבע משני הצדדים,
ומדפדפים באלבום שבו כל דף מותאם לגודל המטבעות שעליו.

## מה בקוד ומה בטלפון
- **בקוד (`catalog.js`)**: ספריית קטלוגים מוכנים, כלומר אילו מטבעות קיימים בסדרה. כרגע:
  קראונים בריטיים 1818–1965, ומטבעות המנדט 1927–1947. אין בקוד שום מידע אישי.
- **בטלפון בלבד (IndexedDB)**: אילו אוספים כל משתמש מחזיק, אוספים שבנה בעצמו, המטבעות שסימן,
  מחירים, הערות ותמונות. גיבוי ושחזור לקובץ JSON מתוך האפליקציה (תפריט ⋯).

כל מי שפותח את הקישור מקבל אלבום ריק משלו ובוחר אילו אוספים להתחיל.

## התקנה באנדרואיד
לפתוח את הכתובת ב-Chrome ← תפריט ⋮ ← "התקנת אפליקציה" / "הוספה למסך הבית".

## הוספת קטלוג לספרייה
להוסיף רשומה ל-`CATALOGS` ב-`catalog.js` עם רשימת המטבעות (שנה, מתכת, קוטר במ"מ).
